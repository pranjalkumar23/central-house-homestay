# The Central House

Marketing and booking site for a vegetarian homestay in Shyamkhet, Bhowali, Uttarakhand — rooms,
photo gallery, and a direct contact/enquiry flow for travelers near Kainchi Dham and Nainital.

**Live at [thecentralhouse.in](https://thecentralhouse.in/)**

## Stack

Static HTML/CSS/JS, multi-page (home, rooms, gallery, contact).
